Forge cross-language HTTP benchmark
Date: 2026-09-09 12:00:20 UTC
Host: Linux 7.1.2-arch3-1 x86_64, 18 cores, 15 GB RAM
Forge: ddae0a8 (http-serving-modes-and-runtime-hardening)
Load: 300000 requests, concurrency 400, 3 runs per server

Every server returns the same 12-byte body and closes the connection.
Forge has no HTTP keep-alive (stdlib/http.c hardcodes Connection:
close), so connection-per-request is the only shape all of these
servers can share. Read rps_per_core, not rps: raw rps rewards a
server for consuming more of the 18 cores.

Runs are round-major -- every server once, then every server again
-- and each one waits for the CPU package to fall back to
78 C before it is timed. This box throttles hard under load,
and without both of those a server's place in the list shows up in
its numbers. Each row records the temperature and mean clock it
started at; if those drift apart across servers, distrust the run.
